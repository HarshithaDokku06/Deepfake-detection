# Deepfake Detection Using CNN and LSTM 

This project focuses on detecting fake images and videos using Deep Learning techniques. CNN is used to extract visual features from images and video frames, while LSTM helps analyze temporal patterns across video frames to identify potential manipulations.

# Technologies Used
- Python
- CNN (Convolutional Neural Network)
- LSTM (Long Short-Term Memory)
- OpenCV
- TensorFlow/Keras

# How It Works
The system processes images and video frames, extracts relevant features, and classifies the input as **Real or Fake** based on the trained model.

# Objective
To explore how deep learning can help identify manipulated digital content and improve the reliability of visual media.

# Future Improvements
- Improve detection accuracy.
- Support real-time video analysis.
- Extend detection to audio and other media formats.

**Domain:** Artificial Intelligence & Deep Learning  
**Model:** CNN-LSTM
